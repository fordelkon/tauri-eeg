# 使用 BioSemi 执行音乐与视频实验

本应用发送事件码并保存实验、试次和量表。ActiView 8.14 连续采集并保存 BDF。本应用不控制 ActiView，也不读取实时脑电。

## 准备设备与素材

1. 连接 BioSemi USB Trigger Interface 到刺激电脑 USB 与 BioSemi Receiver 的 trigger 接口。
2. 在桌面应用中打开 **实验设置**，刷新 COM 端口并连接触发盒。
3. 在 ActiView 启动一段短 BDF 保存。
4. 点击 **发送测试 Trigger**，检查测试码 254 是否进入 ActiView 与 BDF。
5. 在 **诱发与视频调控素材** 中选择素材库，点击 **验证并保存素材库**。
6. 音乐实验先在音乐调控页生成所需曲目，再进入效果评价。

串口固定为 115200、8N1、无流控。软件写入成功只表示发送完成，不能代替第 4 步的 BDF 检查。

## 排练完整流程

1. 在实验设置选择 **排练**。
2. 打开 **效果评价**，填写被试、情绪、条件、手段与时长。
3. 进入诱发，等待视频预载，再开始播放。
4. 视频结束后完成诱发后量表。
5. 执行所选条件。音乐先选曲并等待预载，点击播放后才开始计时。视频从首次播放开始计时。自然恢复从开始静息计时。
6. 到时结束条件，完成后测并查看结果。

排练保存实验日志与量表，不发送硬件 trigger，也不进入正式跨条件比较。默认模式为排练。

## 执行正式实验

1. 在 ActiView 启动本次 BDF 保存。
2. 打开实验设置，选择 **正式实验**，填写计划 BDF 记录名。
3. 勾选 **我已在 ActiView 启动本次 BDF 保存**。
4. 在效果评价中按排练顺序运行。本应用等待实验开始标记写入后启动诱发视频。
5. 实验结束后，在 ActiView 手动停止保存。
6. 返回实验设置，刷新 **实验记录**，为对应 run 关联实际 BDF 文件。
7. 点击 **导出实验日志**，选择目录。软件在该目录创建新的实验子目录，不覆盖已有导出。

每次正式实验都需重新确认外部保存。运行中固定素材，不支持任意切歌、暂停或跳播。页面重载与发送故障会中断实验，软件不补发旧开始标记。

## 执行逐试次范式

1. 在实验设置准备正式模式与 BDF 保存，或选择排练。
2. 打开 **实验范式**，选择个人校准或独立诱发。
3. 填写被试 ID、会话运行 ID，核对素材队列。
4. 开始实验，按静息、提示、视频、试后静息、SAM 的顺序推进。
5. 完成后关联 BDF 并导出日志。

个人校准保留平静类 5 个试次。独立诱发保留焦虑、抑郁、恐惧三个块，每类 5 个试次。模拟脑状态反馈不提供正式实验入口。SAM 质量判定不能代替离线 EEG 伪迹检查。

## 处理失败与查看数据

若播放或 Trigger 出错，停止当前实验并检查素材、连接和 ActiView。保留失败 run 与原 BDF，重新开始新的 run。不要通过重新播放或补发 trigger 把旧记录改成正常完成。

导出包括 `manifest.json`、`events.tsv` 与 `trials.json`。清单包含 run 参数、事件定义、BDF 关联和量表记录。脑电切段以 BDF Status 的样本位置为准，日志用于识别素材、条件与异常。

正式条件比较排除排练、中止和中断记录。不提供旧内部 EEG 记录兼容；软件不会删除已有数据库文件或原始 BDF。

当前打标基于软件播放事件，尚未验证显示器和耳机的物理延迟。用于 ERP 前，另做物理刺激与 trigger 的偏差、抖动测量。

实现规格与事件编码见 [BioSemi 改造文档](biosemi-trigger-implementation.md)。
