# 使用 BioSemi 执行音乐与视频实验

适用设备：BioSemi ActiveTwo、USB Receiver 和 USB Trigger Interface。采集软件：ActiView 8.14。更新日期：2026-10-08。

本应用发送事件码并保存实验、试次和量表。ActiView 8.14 连续采集并保存 BDF。本应用不控制 ActiView，也不读取实时脑电。

## 从这里开始：按五步准备一次实验

打开 tauri-eeg 的 **实验设置**，按页面的五步完成准备。用 **下一步**继续，用 **上一步**修改设置。先完成一次空载连接测试，再准备正式被试实验。

### 第一步：选择实验

先按实验目的选择流程，避免把个人校准当作效果评价。

| 你的目的 | 选择的流程 | 接下来运行的内容 |
|---|---|---|
| 比较音乐、视频或自然恢复的效果 | 效果评价 | 情绪诱发、诱发后量表、条件执行、条件后量表、结果 |
| 采集被试个人平静基线 | 逐试次范式，进入后选择个人校准 | 平静类 5 个试次 |
| 采集各类情绪诱发反应 | 逐试次范式，进入后选择独立诱发 | 焦虑、抑郁、恐惧，每类 5 个试次 |

接着选择模式。

- 只熟悉页面、播放和量表操作时，选择 **排练 · 不发送硬件 Trigger**。排练记录日志，但流程事件不发到硬件。
- 要测试完整硬件打标或采集被试数据时，选择 **正式实验 · 发送 Trigger**。正式模式需要连接触发盒，并确认 ActiView 正在保存。
- 不戴帽也可以用正式模式做空载测试。被试 ID 和 BDF 文件名写明 `test`，这份数据仅用于验证连接、保存和打标。

只打开一个 tauri-eeg 窗口。在同一个窗口选择模式并进入流程。模式按窗口会话保存，重启或换窗口后重新检查，不要以为上次的正式模式仍然有效。

### 第二步：连接与测试

1. 点击 **刷新端口**，选择 USB Trigger Interface 的端口，例如 COM5。
2. 点击 **连接触发盒**。
3. 确认页面显示 **触发盒 已连接 · COM5**。连接失败时，先处理错误，再继续。
4. 首次使用或更换连接后，在 ActiView 保存一份短测试 BDF。详细步骤见下方“空载测试采集、保存和打标”。
5. 在 tauri-eeg 点击一次 **发送测试 Trigger**，确认返回测试码 254 已写入串口的提示。
6. 在测试 BDF 中核对 254，确认码值和次数。测试完成后正常结束测试文件，正式流程另建 BDF。

**发送测试 Trigger**在排练模式也可使用。它只发送测试码，不会启动效果评价或逐试次范式。测试提示证明串口写入完成，BDF 核对才证明硬件收到并保存了标记。

### 第三步：准备素材

1. 点击 **选择文件夹**，选择素材库根目录。
2. 点击 **验证并保存素材库**。
3. 检查验证结果和各类视频数量，处理缺失或无效素材。
4. 如果运行音乐效果评价，先在音乐调控页准备所需曲目，再返回实验设置。

效果评价、个人校准、独立诱发和视频调控共用该素材库。个人校准使用平静素材，独立诱发使用焦虑、抑郁和恐惧素材。

### 第四步：保存脑电

排练不要求保存 BDF。正式模式每次启动新实验前执行以下步骤。

1. 切换到 ActiView 8.14。
2. 点击左上角 **Start**。已经采集则不重复点击。
3. 确认采样率非零、数据持续更新。当前设备配置显示 2048 Hz。
4. 选择 **Save Subset**，包含本次需要的 EEG、EXG 和传感器通道。
5. 点击右上角 **Start File**，填写本次文件路径和记录信息。
6. 确认绿色 **Saving**，保存秒数和文件大小持续增加。
7. 回到同一个 tauri-eeg 窗口，在 **BDF 记录名**填写与实际文件一致的名称。
8. 勾选 **我已在 ActiView 启动本次 BDF 保存**。

例如，效果评价文件可命名为 `test_effect_music_run01.bdf`，个人校准文件可命名为 `test_calibration_run01.bdf`。一份文件对应一次运行便于核对。

勾选保存确认不会启动 ActiView，也不会检查磁盘文件。你必须先看到 ActiView 的保存计数增长，再勾选。每次正式实验会消耗这次确认，下次运行需要重新确认。

### 第五步：核对并进入

开始前核对页面中的流程、模式、素材库、触发盒状态和 BDF 记录名。

1. 如果要做音乐、视频或自然恢复效果评价，点击 **进入效果评价**。
2. 如果要做个人校准或独立诱发，点击 **进入逐试次范式**，再选择对应实验类型。
3. 在流程页面填写被试 ID 和本次运行参数。
4. 再次检查模式。逐试次范式有独立的模式开关，正式运行时确认显示 **正式 · 发送 Trigger**。若显示 **排练 · 不发送 Trigger**，点击开关切换。
5. 完成页面的准备后开始实验。不要在运行中手动反复发送测试码。

逐试次页面默认选择个人校准。要做效果评价时，不要通过逐试次入口启动。此前 Testdata 的核对已证明个人校准标记成功，该结果不能代替效果评价流程的验证。

开始后以本次实际运行模式和实验日志为准。页面中的素材、被试 ID 或已连接状态，都不能证明流程正在发送硬件 Trigger。

## 两个软件如何配合

按照下表完成一次效果评价。ActiView 连续保存，tauri-eeg 按流程自动发送事件码。

| 阶段 | ActiView 操作 | tauri-eeg 操作 | 核对结果 |
|---|---|---|---|
| 准备 | 开始采集 | 选择效果评价和正式模式，连接 Trigger，验证素材 | 采样率非零，Trigger 已连接 |
| 开始记录 | 新建本次 BDF，开始保存 | 填写 BDF 记录名，勾选保存确认 | Saving，保存秒数增长 |
| 配置评价 | 保持保存 | 填写被试、目标情绪、条件时长，选择自然恢复或音乐、视频调控 | 本次流程和模式正确 |
| 情绪诱发 | 保持保存 | 点击 **确认配置，开始诱发**，按页面提示开始并完成视频 | 自动记录诱发开始和结束事件 |
| 诱发后量表 | 保持保存 | 完成并提交诱发后量表 | 量表已提交 |
| 条件执行 | 保持保存 | 自然恢复按页面静息；音乐或视频先完成预载，再开始播放 | 条件计时开始，自动记录事件 |
| 条件后量表 | 保持保存 | 条件结束后完成并提交量表，查看结果 | 流程正常完成 |
| 文件收尾 | 点击 **Stop**，正常结束采集和文件保存 | 返回实验设置的 **实验记录** | BDF 不再增长，运行状态为完成 |
| 保存证据 | 用 ActiRead 或离线工具回读 BDF | 关联 BDF，导出实验日志 | 码值、顺序和数量与日志对应 |

若要比较两种条件，对同一被试和目标情绪分别完成自然恢复与调控条件。每次新运行都重新确认 ActiView 保存。

## 完成后关联 BDF 并核对日志

1. 先完成或正常中止 tauri-eeg 流程，再结束 ActiView 保存。
2. 在 **实验记录**点击 **刷新记录**。
3. 根据被试 ID、开始时间和运行 ID 找到本次记录。
4. 展开记录，核对模式、状态和实验类型。效果评价与 `personal_calibration` 不是同一流程。
5. 点击 **关联 BDF 文件**，选择实际保存的文件。ActiView 若拆分成多个文件，关联本次运行的全部 BDF。
6. 点击 **导出实验日志**，选择导出目录。
7. 回读 BDF 的 Status 通道，将低 8 位事件码的顺序和次数与导出的 `events.tsv` 对照。

关联文件只是记录路径，不会自动验证 BDF 中的标记。只有测试码 254，不能证明正式流程事件已保存。中止时的结束事件也不能当作正常完成。

如果没有正常停止 ActiView，文件头记录数可能仍为 `-1`。先让 ActiView 完成文件收尾，再回读核对。

## 1. 连接设备

1. 将配套电池连接到 ActiveTwo 采集盒。
2. 将 ActiveTwo 的光纤输出连接到 USB Receiver 的光纤输入。
3. 将 USB Receiver 的 USB 线连接到运行 ActiView 的采集电脑。
4. 将 USB Trigger Interface 的 USB 线连接到运行 tauri-eeg 的刺激电脑。
5. 将 USB Trigger Interface 的 37 针端连接到 USB Receiver 的 Trigger 接口。
6. 打开 ActiveTwo 电源。

采集和刺激可以使用同一台电脑，也可以使用两台电脑。两台电脑时，COM 端口在刺激电脑上查看。当前设备此前识别为 COM5；重新插拔后，以设备管理器和应用刷新得到的端口为准。

只保留一个 tauri-eeg 实例。关闭其他占用触发盒端口的串口测试程序。USB Receiver 和 USB Trigger Interface 是两个设备，COM5 的识别不能代替 USB Receiver 的识别。

## 2. 空载测试采集、保存和打标

本节用于不戴脑电帽的连接测试。空载时波形、Offset 和 CM in Range 可能异常，不能据此评价电极接触，也不能将测试文件作为被试脑电。

### 2.1 在 ActiView 开始保存

1. 打开 ActiView 8.14。
2. 点击左上角 **Start**。如果采集已经运行，不重复点击。
3. 确认波形持续更新，右侧 **Sample Rate [Hz]** 为非零值。当前常规配置为 2048 Hz，带宽显示为 417 Hz；其他配置按实际采样率判断。
4. 在右侧 **Save Subset** 选择需要保存的通道。64 通道测试可选择 **A1–B32 (64)**。
5. 点击右上角 **Start File**。
6. 在弹出的窗口中完成保存路径、文件名和记录信息，保存到本地文件夹。示例文件名为 `connection_test.bdf`。
7. 如果 **Pause File** 处于暂停状态，解除暂停。
8. 确认右上角显示绿色 **Saving**，**Nr of Files** 至少为 1，**Current File [MB]** 和 **Total Saved [sec]** 持续增加。

左上角 Start 启动采集，右上角 Start File 启动文件保存。仅有滚动波形不能证明 BDF 已保存。

### 2.2 检查测试码是否会控制保存

1. 检查 ActiView 当前加载的配置文件中的 **PauseOff** 和 **PauseOn**。
2. 如果用 254 控制暂停或恢复保存，先备份配置文件。
3. 本次测试要求连续保存且不使用触发码控制暂停时，将这两项的值设为 **-1**，保留配置文件原有格式。
4. 重新加载修改后的配置。若需停止采集才能加载，加载后重新执行上一节的采集和保存步骤。

项目发送的测试码是 254。ActiView 可以使用触发码控制暂停保存，不能把测试码引起的保存状态变化误判为故障。配置规则见 [BioSemi 触发信号说明](https://www.biosemi.com/faq/trigger_signals.htm)。

### 2.3 在 tauri-eeg 连接和发送

1. 打开已包含串口发送修复的 tauri-eeg 桌面程序，登录后进入左侧 **实验设置**。
2. 在 **Trigger 接口**区域点击 **刷新端口**。
3. 在 **COM 端口**中选择触发盒端口，例如 **COM5**。
4. 点击 **连接触发盒**，确认页面显示 **触发盒 已连接 · COM5**。
5. 确认 ActiView 的保存秒数仍在增加。
6. 点击一次 **发送测试 Trigger**。
7. 确认按钮结束加载，页面提示 **测试码 254 已写入串口。请在 ActiView 和短 BDF 中确认标记。**
8. 若第一次操作正常返回，间隔约 2 秒再发送两次，总共发送 3 次，并记录测试次数。

单独发送测试码不要求将实验模式改成正式实验。实验运行期间测试按钮不可用。串口参数由项目固定为 115200、8N1、无流控，无需手动输入。协议见 [BioSemi USB Trigger Interface 操作说明](https://www.biosemi.com/faq/USB%20Trigger%20interface%20cable.htm)。

### 2.4 在 ActiView 和 BDF 中确认

1. 切回 ActiView 的 **Monopolar** 页面。
2. 在触发显示格式选项中选择数字显示。不同界面可能显示为 **Digital** 或 **Decimal**；如选项被窗口裁切，扩大窗口查看。
3. 检查底部 **Trig 1–8** 的事件值是否为 **254**。单条红色竖线不能证明码值正确。
4. 保持保存约 10 秒。
5. 点击采集 **Stop** 正常结束本次采集，完成可能出现的文件结束提示，确认保存停止。不要直接强制结束 ActiView。
6. 用 **ActiRead** 打开测试 BDF，检查记录时长，并在测试位置核对 3 次 **254**。
7. 记录实际 BDF 路径和核对结果。若需要他人检查，将该路径与测试次数一起提供。

核对的是 Trigger 输入 1–8 的低 8 位码值。离线工具如果显示完整 Status 数值，需先提取低 8 位，不能直接将完整状态值与 254 比较。

验收必须同时满足：ActiView 接收数据、BDF 可以正常打开、BDF 中的测试码值和次数符合发送记录。tauri-eeg 显示写入成功只证明串口写入完成，截图中的 Saving 和文件计数只证明保存正在进行。

## 3. 连接或发送失败时处理

### 连接触发盒显示拒绝访问

1. 关闭所有 tauri-eeg 窗口。
2. 在任务管理器确认没有残留的 `tauri-eeg.exe`。
3. 关闭其他串口测试程序。
4. 重新插拔 USB Trigger Interface，确认设备管理器中的端口名称。
5. 只启动一个已修复的 tauri-eeg 实例。
6. 进入实验设置，刷新端口，重新连接。

Windows 串口采用独占访问。另一程序或残留实例占用端口时，新的连接可能被拒绝。设备管理器显示 COM5 正常，不表示端口当前可供应用打开。见 [微软串口访问说明](https://learn.microsoft.com/en-us/windows/win32/devio/communications-resource-handles)。

### 发送测试一直转圈

1. 不要重复点击，也不要开始正式实验。
2. 查看 ActiView 是否出现事件，并保留当前测试 BDF。发送结果未返回不等于字节一定没有发出。
3. 关闭 tauri-eeg，确认旧进程退出，再重新插拔触发盒。
4. 使用包含发送修复的程序重新测试。旧快捷方式可能仍打开旧版本。
5. 若仍无法返回，记录程序版本、COM 端口、连接是否成功，以及 ActiView 是否收到事件，再继续排查。

旧发送实现调用 Windows 串口刷新，可能不受写入超时约束。修复后的实现保留串口写入检查，移除该刷新等待。硬件是否收到事件仍以 BDF 为准。见 [微软串口读写说明](https://learn.microsoft.com/en-us/windows/win32/devio/read-and-write-operations)。

### ActiView 采样率为 0 或出现 Error 5000

1. 确认 ActiveTwo 的 POWER 灯亮。
2. 检查光纤两端连接。
3. 检查 USB Receiver 的 USB 线是否接到采集电脑。
4. 检查接收器的 **Optic Link** 灯，以及启动采集时 **USB Link** 是否闪烁。
5. 必要时换电脑 USB 接口，按 [BioSemi Error 5000 排查说明](https://www.biosemi.com/faq/AD-box%20shuts-down%20or%20Acquisition%20stops.htm)检查接收器识别。

## 4. 准备素材并排练完整流程

1. 在 **实验设置 → 诱发与视频调控素材**中选择素材库。
2. 点击 **验证并保存素材库**。
3. 音乐实验先在音乐调控页生成所需曲目，再进入效果评价。

1. 在实验设置选择 **排练**。
2. 打开 **效果评价**，填写被试、情绪、条件、手段与时长。
3. 进入诱发，等待视频预载，再开始播放。
4. 视频结束后完成诱发后量表。
5. 执行所选条件。音乐先选曲并等待预载，点击播放后才开始计时。视频从首次播放开始计时。自然恢复从开始静息计时。
6. 到时结束条件，完成后测并查看结果。

排练保存实验日志与量表，不发送硬件 trigger，也不进入正式跨条件比较。默认模式为排练。

## 5. 执行正式实验

1. 在 ActiView 启动本次 BDF 保存。
2. 打开实验设置，选择 **正式实验**，填写计划 BDF 记录名。
3. 勾选 **我已在 ActiView 启动本次 BDF 保存**。
4. 在效果评价中按排练顺序运行。本应用等待实验开始标记写入后启动诱发视频。
5. 实验结束后，在 ActiView 手动停止保存。
6. 返回实验设置，刷新 **实验记录**，为对应 run 关联实际 BDF 文件。
7. 点击 **导出实验日志**，选择目录。软件在该目录创建新的实验子目录，不覆盖已有导出。

每次正式实验都需重新确认外部保存。运行中固定素材，不支持任意切歌、暂停或跳播。页面重载与发送故障会中断实验，软件不补发旧开始标记。

## 6. 执行逐试次范式

1. 在实验设置准备正式模式与 BDF 保存，或选择排练。
2. 打开 **实验范式**，选择个人校准或独立诱发。
3. 填写被试 ID、会话运行 ID，核对素材队列。
4. 开始实验，按静息、提示、视频、试后静息、SAM 的顺序推进。
5. 完成后关联 BDF 并导出日志。

个人校准保留平静类 5 个试次。独立诱发保留焦虑、抑郁、恐惧三个块，每类 5 个试次。模拟脑状态反馈不提供正式实验入口。SAM 质量判定不能代替离线 EEG 伪迹检查。

## 7. 处理实验失败与查看数据

若播放或 Trigger 出错，停止当前实验并检查素材、连接和 ActiView。保留失败 run 与原 BDF，重新开始新的 run。不要通过重新播放或补发 trigger 把旧记录改成正常完成。

导出包括 `manifest.json`、`events.tsv` 与 `trials.json`。清单包含 run 参数、事件定义、BDF 关联和量表记录。脑电切段以 BDF Status 的样本位置为准，日志用于识别素材、条件与异常。

正式条件比较排除排练、中止和中断记录。不提供旧内部 EEG 记录兼容；软件不会删除已有数据库文件或原始 BDF。

当前打标基于软件播放事件，尚未验证显示器和耳机的物理延迟。用于 ERP 前，另做物理刺激与 trigger 的偏差、抖动测量。

实现规格与事件编码见 [BioSemi 改造文档](biosemi-trigger-implementation.md)。
