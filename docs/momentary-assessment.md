# 情绪调控前后的测量选择

日常调控入口采用两项自编强度记录（紧绷、不愉快，0–3）。两项只描述当下体验，单独标识版本，不设临床阈值。正式效果评价默认在诱发结束、条件结束时各记录三项 1–9 分评分。简版分别报告后测减前测的原始分差。研究者可在开始前切换为完整量表，音乐调控条件为 43 + 49 题，其余为 43 + 40 题。

| 工具 | 适用目的 | 对本项目的建议 |
| --- | --- | --- |
| [PHQ-4 原始研究](https://pubmed.ncbi.nlm.nih.gov/19996233/) | 四题筛查过去两周的焦虑、抑郁症状 | 需要筛查时单独安排。数分钟内的调控前后测量应使用状态指标。 |
| [SAM 原始研究](https://pubmed.ncbi.nlm.nih.gov/7962581/) | 三次图形判断分别描述愉悦度、唤醒度、控制感 | 跨音乐、视频与自然恢复，可在诱发结束和条件结束时各测一次，分别报告变化。唤醒度上升或下降没有统一的改善方向。现有中文数字界面属于改编形式，原研究未验证其等效性。 |
| [中文版 STAI 短版研究](https://pubmed.ncbi.nlm.nih.gov/35619610/) | 状态与特质各六题 | 若预先指定状态焦虑为主要结局，考虑只用状态分量表。部署前核对该中文版本、电子施测授权和计分规则，不能从现有二十题中自行抽六题。 |

简版使用独立标识 momentary_vad_3_v1，只和同版本记录配对。若研究问题要求区分恐惧与焦虑，三维评分本身无法确定情绪类别。条件由研究者预设，在完成后测前隐藏组别、目标标签和分数反馈；同样保留对材料可能引发不适的说明和退出操作。
