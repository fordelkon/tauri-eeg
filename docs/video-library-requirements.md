# 范式视频库要求（素材准备指南）

> 面向范式采集（个人校准 / 独立诱发调控）与调控反馈闭环范式（试运行）的素材库建设要求。
> 代码读取逻辑见 `src-tauri/src/paradigm/video.rs`；时长判定见 `src/paradigm/paradigmTimeline.ts`。

## 1. 目录结构（代码强制约定）

视频根目录下按**情绪类别子目录**组织，子目录名大小写不敏感，必须是以下英文名：

```
video_paradigm/            ← 根目录（在采集页"选择视频根目录"指定）
├── Anxiety/    *.mp4      ← 焦虑诱发（必填）
├── Depression/ *.mp4      ← 抑郁诱发（必填）
├── Calm/                    ← 平静素材（必填）
│   ├── healing_animation/*.mp4
│   ├── music/*.mp4
│   ├── scenery/*.mp4
│   ├── sound_relaxation/*.mp4
│   └── vlog/*.mp4
├── Fear/       *.mp4      ← 恐惧诱发（必填）
└── Calm/       *.mp4      ← 平静素材
```

- 递归扫描每个情绪目录内的 `.mp4` 扩展名（大小写不敏感）；txt/jpg 等会被忽略。嵌套素材以相对于情绪目录的路径排序，并以该相对路径生成 `video_id`，避免不同分类下同名文件冲突。
- 每个类别的视频按**相对路径排序**入队；队列由 `session_run_id` 做确定性洗牌（同 run id 同队列，跨被试可复现）。
- **校验规则**：凡参与当前实验排程的类别，目录缺失或 `.mp4` 数量 < 5 会导致整个视频库校验失败（`valid=false`），实验设置页会列出具体问题文案。

## 2. 数量要求（分阶段）

| 阶段 | 每类数量 | 说明 |
|---|---|---|
| 当前管线联调（R8 过渡） | ≥ 5 | 代码硬性下限 `MIN_VIDEOS_PER_CLASS = 5` |
| 调控反馈闭环正式实验 | ≥ 12 | 每个 run 消耗 3 类 × 5 试次；≥12 才能保证相邻 run 不重复 |
| 大纲 S-04 终态 | 50/类 | 支持多 session 纵向训练与标定/调控素材分离 |

当前界面会将 S-04 的焦虑、抑郁、恐惧三类不足 50 条显示为**内容就绪提醒**，但不会阻断不少于 5 条的联调运行。

> 当前效果评价的“视频调控”从 `Calm/` 池播放素材，个人校准也使用 Calm 池。正式实验前应把平静基线和视频调控素材分为互不重叠的两个池，并在素材台账中冻结其分配；当前文件夹尚未表达这一层区分，因此不能据此声称已满足“标定与调控素材分离”的方法学要求。

**标定与调控的素材必须分离**：个体化分类器标定用的素材不能在调控 run 里重复出现（防止"看过就调不动"）。按 50/类 的终态目标准备时，天然满足这一约束。

## 3. 技术规格

| 项 | 要求 | 原因 |
|---|---|---|
| 容器/编码 | MP4，H.264（High profile）+ AAC 音频 | WebView2/Chromium 原生可解码，Tauri `convertFileSrc` 直接播放 |
| 分辨率 | ≥ 1280×720，推荐 1920×1080 | 全屏呈现（OS 级全屏）不糊 |
| 帧率 | 25 或 30 fps 恒定 | 变帧率会影响后续帧级对齐 |
| 时长 | **45–90 秒**（当前强制区间） | 范式引擎的 `isVideoDurationOutOfRange` 会给越界视频打警示徽章，并在 qualityCheck 自动计入 `video_duration_out_of_range` → 试次被判 `artifact_rejected` |
| 音量 | 响度归一（建议 −23 LUFS ±2），片段间响度差异 < 3 dB | 跨试次/跨类别可比 |
| 画面 | 无水印、无台标、无内嵌字幕 | 内嵌字幕会污染情绪诱发与眼动 |
| 文件名 | `小写类别_vidNN.mp4`（如 `anxiety_vid03.mp4`），避免中文与空格 | video_id 即文件名主干，进数据库与 JSONL 事件流 |

> 注意：闭环范式设计稿中调控 run 的诱发片段目标时长是 30–45 s；在放宽 `VIDEO_MIN_SECONDS` 之前，请按 45–90 s 选片，或统一放宽时长检查并同步改测试。

## 4. 内容标准

1. **诱发效力优先**：优先选用有常模数据的片段（效价/唤醒评分），而不是"感觉像"的主观判断。
2. **可重评性**（调控范式的关键要求）：片段必须包含**可以被认知重评的叙事内容**——有人物、有情境、有可重新解读的事件。纯感官刺激（如音乐 MV、风景）缺乏重评抓手，不适合调控 run。
3. **伦理边界**：不含真实血腥、自伤、虐待画面；恐怖类用心理悬念而非 jump scare 堆叠；焦虑/抑郁类避免直指自杀内容。所有素材需通过实验室伦理审查备案。
4. **类别纯粹性**：每个片段只归入一个类别；混合情绪（如"又怕又悲"）降级为备选。

## 5. 推荐素材来源

| 来源 | 内容 | 获取方式 | 许可注意 |
|---|---|---|---|
| **EmoStim**（Somarathna et al., 2024, IEEE TAC） | 99 个可靠情绪诱发视频，离散+成分模型双标注 | 公开托管，直接下载：[Yareta 仓库](https://yareta.unige.ch/archives/3476077e-5a1c-4572-a99b-1dada060384f) | 引用出处；核对单片段许可 |
| **中国标准化情绪短视频库**（Duan et al., 2023, PLOS ONE） | 240 个标准化短视频（2700 初筛 + 360 人常模），含年龄/性别常模 | 论文开放获取，按文中联系方式向作者申请 | 论文附录注明使用范围 |
| **LIRIS-ACCEDE** | 9800 段 8–12 s 片段（160 部 CC 电影），VA 排序 | 签 EULA 扫描后发 accede@liris.cnrs.fr | 片段短（8–12 s），需串联使用；CC-BY/SA/NC 混合，逐段核对 |
| **FilmStim**（Schaefer et al.） | ~70 个经典电影片段，法语/英语常模 | [UCLouvain 页面](https://sites.uclouvain.be/ipsp/FilmStim/) 签使用协议 | 仅限研究用途 |
| **Ge et al. 2018 中文情绪电影库** | 标准化中文电影片段 | [Figshare](https://tandf.figshare.com/articles/dataset/A_standardised_database_of_Chinese_emotional_film_clips/7177595) | 引用出处 |
| 自摄/自制 | 补齐特定类别 | 自主控制时长与内容 | 需演员/场地授权 |

**优先级建议**：正性类别从 EmoStim + 中国短视频库补充（当前库存完全没有正性素材，是调控范式的最大缺口）；负性三类先从现有库扩到 12/类，再按常模数据替换弱片段。

## 6. Pilot 评分协议（入库前筛选）

1. 评分人：实验室成员/同质人群 ≥ 20 人（记录性别、年龄）。
2. 工具：SAM 量表（效价/唤醒/支配，1–9），看完即评；每片段间 ≥ 15 s 洗脱。
3. 筛选阈值（每片段取均值）：
   - 焦虑/抑郁/恐惧：效价 ≤ 4 且唤醒 ≥ 5，类别间效价差异显著；
   - 平静：效价 4–6 且唤醒 ≤ 4；
4. 剔除评分标准差过大（评分人分歧 > 2.5）的片段；落选片段降级为标定候补。

## 7. 常见校验错误对照

| 页面提示 | 原因 | 处理 |
|---|---|---|
| `Missing video subdirectory: X.` | 缺少类别子目录 | 按第 1 节建目录 |
| `X requires at least 5 MP4 files (found N).` | 该类 mp4 不足 5 个 | 补片或减少该类别的排程 |
| 试次徽章"视频时长超出 45-90 秒范围" | 片段时长越界 | 重剪或换片；会被自动判 artifact_rejected |
| 选择根目录后提示"视频库校验未通过" | 上述问题汇总 | 按问题列表逐项修复（校验通过才会记住路径） |

## 8. 独立视频调控页的选择方式

首页的"视频调控"直接扫描 `video_paradigm/Calm/` 中的 MP4 文件，包含分类子目录。首次打开使用实验设置已保存的视频根目录；没有保存路径时，使用项目中的 `video_paradigm` 文件夹。

页面按实际文件所在的分类显示"治愈动画"、"音乐"、"风景"、"声音放松"、"日常影像"等选项。选择分类后，可通过"搜索视频"按文件名、分类名或相对路径筛选，再点击对应文件的"播放"。不同分类下的同名文件各自保留，可以分别播放。

点击"选择视频根目录"可切换到其他包含 `Calm/` 的视频根目录，应选择 `video_paradigm` 这一层。页面记住成功加载的路径，下一次进入时自动恢复。独立视频调控页保存的路径不改变实验设置中的素材库路径。

独立浏览只需要 `Calm/` 中有可用 MP4，不要求诱发目录齐全或每类达到 5 个文件。实验采集的校验要求仍按前文执行。空目录和浏览器预览不会展示虚构的视频或标签；本地扫描和文件播放需使用桌面应用。

页面内智能助手使用当前加载的文件清单和文件夹分类，不再推荐旧标签索引中的视频。

开发验证使用 `tests/video-regulation-ui-smoke.cjs` 检查目录选择、搜索、播放入口和小窗口布局，使用 `tests/verify-real-regulation-library.cjs` 检查真实 `Calm/` 文件清单与一条实际 MP4。两个脚本需要 Playwright 和运行中的预览，`VIDEO_REGULATION_SMOKE_URL` 指定预览地址；真实素材脚本可通过 `VIDEO_REGULATION_LIBRARY_ROOT` 指定根目录。脚本模拟桌面扫描返回值，实际素材检查从本地文件读取视频字节。
